# tea-mail-shop

iOS app for the tea shop tea-mail.by built with SwiftUI. Supports browsing products, a shopping cart, localization, offline caching, analytics and crash reporting.

![demo-optimized](https://github.com/user-attachments/assets/3e9d1670-cb30-40cf-ae88-e4efb9cee201)

[▶ Full demo video](https://youtube.com/shorts/AATIoQoc2Bg?feature=share)

## Key features

- Built with **SwiftUI**.  
- Firebase integration: **Analytics**, **Crashlytics**, **Firestore**.  
- Offline caching of the tea catalog from a REST API using **Realm**.  
- Localization: **English (EN)** and **Russian (RU)**.  
- Lottie animations (empty cart state).  
- Core business logic covered by **XCTest** unit tests for stability.

## Tech stack

- Swift, SwiftUI  
- Xcode 15.2
- Firebase (Analytics, Crashlytics, Firestore)  
- Realm  
- Lottie  
- XCTest

## How to run
You need [Xcode 15.2 or higher](https://apps.apple.com/by/app/xcode/id497799835?mt=12) to run this app
1. Clone the repository: go to the Terminal and run `git clone git@github.com:ozzyasha/tea-mail-shop.git` (if you're using SSH key) or `git clone https://github.com/ozzyasha/tea-mail-shop.git`
2. Open Xcode, choose "File" -> "Open..." (`⌘O`), go to "tea-mail-shop" folder and open .xcodeproj file
3. Choose needed simulator, run the project (`⌘R`)

## Run tests
Run unit tests in Xcode: Product → Test (`⌘U`).
